
# NewsLens AI

**AI-Based News Bias and Framing Analysis System**

## Overview

NewsLens AI is an AI-powered mobile platform that collects news articles from multiple sources, identifies articles covering the same events, and compares how different sources present those events.

The platform provides evidence-based analysis of news framing, language, topics, entities, quotes, and political signals.

## Core Features

- Automated news collection using RSS feeds and APIs
- Related news event detection
- Article-level framing analysis
- Sentiment and emotion analysis
- Named entity and topic extraction
- Political and party-related signal analysis
- Cross-source news comparison
- Interactive evidence-based reports

## Technology Stack

- Mobile: React Native and Expo
- Backend: Node.js and Express
- Database: PostgreSQL and Prisma
- AI/ML: Python and Hugging Face Transformers
- Version Control: Git and GitHub

## Project Structure

- `mobile/` – Mobile application
- `backend/` – Backend APIs
- `ai-engine/` – NLP and AI services
- `docs/` – Project documentation
