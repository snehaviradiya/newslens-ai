# NewsLens AI — Mobile Application

## Overview

The `mobile/` module houses the cross-platform mobile client for NewsLens AI, developed with **React Native**, **Expo**, and **TypeScript**.

The application provides an intuitive, interactive reader interface to explore news events across multiple outlets, examine article-level framing and sentiment, contrast headlines side-by-side, and inspect evidence-backed analytical reports.

## Planned Technology Stack

- **Framework:** React Native with Expo (Managed Workflow)
- **Language:** TypeScript
- **Navigation:** React Navigation (Native Stack & Bottom Tabs)
- **State Management & Data Fetching:** React Hooks / Context API / Axios
- **UI Components:** React Native Paper / Tailwind (NativeWind) / Custom design system
- **Icons & Visuals:** Expo Vector Icons, SVG Charts

## Key User Interfaces

1. **Dashboard / Feed:** Real-time news stories clustered by shared events with source diversity indicators.
2. **Event Perspective Comparison:** Side-by-side comparative views of multiple articles reporting on the same event.
3. **Article Detail & Deep Analysis:** Transparent, evidence-based breakdown of framing, tone, entities, quotes, and political signals.
4. **Interactive Bias & Framing Visualizer:** Graphical radar and spectrum charts comparing framing nuances without simplistic one-dimensional labels.
5. **Saved Reports & History:** Bookmarked comparative investigations and reading history.
